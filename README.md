# dt-llm-experiments

A framework and accompanying analyses for systematically studying large language model (LLM) behavior in terms of capabilities and dispositions in decision-theoretic and anthropic reasoning problems.

The repository is organised into two self-contained subprojects:

## [`dt-llm-bsc/`](./dt-llm-bsc)

**Bachelor's thesis** (May 2025): LLM behavior in Newcomb-like decision problems with a focus on the contrast between causal decision theory (CDT) and evidential decision theory (EDT) recommendations. See [`dt-llm-bsc/README.md`](./dt-llm-bsc/README.md).

## [`anthropics-llm-msc/`](./anthropics-llm-msc)

**Master's thesis** (May 2026): Extends the framework to anthropic reasoning problems with a focus on the contrast between the Self-Sampling Assumption (SSA) and Self-Indication Assumption (SIA) as the normative principles. See [`anthropics-llm-msc/README.md`](./anthropics-llm-msc/README.md).

Each subproject shares a common methodological ancestry (descriptive question types about decision-theoretic / anthropic reasoning principles, expressed attitude questions; algorithmically variated problem templates) but use different problem families, normative principles, and models and their APIs.
